class reactormodels.models.AdvectionDiffusionAdsorption(breakthrough: Breakthrough, isotherm: Isotherm, numerics: NumericsConfig, mode: AdsorptionKinetics = AdsorptionKinetics.LOCAL_EQUILIBRIUM, k_ldf: float = 0, inlet_bc: Type[InletBC] = <class 'reactormodels.models.boundary_conditions.DanckwertsBC'>)[source]

Bases: object

1D advection-diffusion with adsorption in a packed bed.

The governing equations are:

Fluid phase: eps*dC/dt + eps * v * dC/dx - eps* D * d2C/dx2 - rho_b * dq/dt = 0 Solid phase: dq/dt = k_l (q*(C) - q) where q is provided isotherm.

If local_equilibirium is assumed, the solid phase equation is ignored and:

dq_dt = dq*/dc*dc/dt

solve(t_span, t_eval, C_in=1.0, C_init=0.0, q_init=0.0)[source]

Integrate from t_span[0] to t_span[1], returning results at t_eval.
