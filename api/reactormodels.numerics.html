class reactormodels.numerics.OrthogonalCollocation(n_interior_points: int = 5, alpha: float = 0.0, beta: float = 0.0, add_inlet: bool = False, n_elements: int = 1)[source]

Bases: object

Generate collocation points and differentiation matrices on [0, 1]

Jacobi polynomials, with optional multi-element support.

Single element (n_elements=1):

Standard global collocation on [0, 1].

Multi-element (n_elements > 1):

Domain split into ne equal elements [k/ne, (k+1)/ne]. Within each element, local collocation applied. Continuity of C enforced at element boundaries. Flux continuity enforced via the continuation condition. This resolves high-Pe oscillations without upwinding.

Parameters:

  • n_interior_points (int Points per element (excludes endpoints))

  • alpha (float Jacobi polynomial parameters)

  • beta (float Jacobi polynomial parameters)

  • add_inlet (bool Add x=0 as first node)

  • n_elements (int Number of elements (default 1))
